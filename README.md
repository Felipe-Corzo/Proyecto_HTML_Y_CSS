# 🐾 Fundación Patitas Felices

**Rescate • Cuidado • Adopción Responsable**

Bienvenido al repositorio del sitio web oficial de **Fundación Patitas Felices**, una organización dedicada a brindar una segunda oportunidad a perros y gatos en situación de abandono.  
En esta plataforma encontrarás información sobre nuestra misión, programas, procesos de adopción y formas de apoyar.

---

## 📌 Descripción del Proyecto

Este proyecto corresponde al desarrollo del **sitio web informativo de la fundación**.  
El objetivo principal es ofrecer un espacio **claro, atractivo y funcional**, donde los usuarios puedan:

- Conocer nuestra labor y propósito.  
- Ver mascotas disponibles para adopción.  
- Entender el proceso de adopción responsable.  
- Ponerse en contacto con la fundación.  
- Donar o convertirse en voluntario.

El sitio está desarrollado con **HTML y CSS puro**, sin frameworks, optimizado para ser **responsive** y **accesible**.

---

## 🧱 Tecnologías Utilizadas

- **HTML5** – Estructura semántica del sitio  
- **CSS** – Estilos, diseño responsive y animaciones  
- **Assets** – Imágenes, íconos, favicons, logos  
- **Git / GitHub** – Control de versiones y despliegue
